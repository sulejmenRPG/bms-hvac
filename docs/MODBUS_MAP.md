# Карта регистров Modbus TCP/RTU // Пищевой цех №1

## 1. Общие спецификации шины связи

- **Протокол:** Modbus TCP (порт 5020) / Modbus RTU (RS-485, 9600 baud, 8N1, 120 Ом EOL).
- **Slave ID (Device ID):** 1.
- **Топология:** Шлейфовая (Daisy-Chain), экранированная витая пара Belden 9841, длина трассы 60 метров.
- **Формат чисел с плавающей точкой:** Фиксированная точка (Fixed-Point) с коэффициентом масштабирования `x10` (значение 192 в регистре соответствует 19.2 °C / 19.2 % Rh).

---

## 2. Таблица Holding Registers (Функция 0x03 / 0x06 / 0x10)

### Зона 1: Горячий цех выпечки (Хлебопекарные печи)

| Адрес (Dec) | Идентификатор | Тип данных | Диапазон | Ед. изм. | Описание |
|---|---|---|---|---|---|
| **0000** | `Z1_TEMP_ACTUAL` | INT16 (RO) | 0 .. 500 | 0.1 °C | Фактическая температура воздуха в зоне выпечки |
| **0001** | `Z1_HUM_ACTUAL` | INT16 (RO) | 0 .. 1000 | 0.1 % Rh | Фактическая относительная влажность воздуха |
| **0002** | `Z1_FAN_SPEED` | INT16 (RW) | 0 .. 100 | 1 % | Мощность приточного VAV-клапана и вытяжного зонта |
| **0003** | `Z1_OVEN_STATUS` | INT16 (RW) | 0 .. 1 | bool | Статус створок ротационной печи (0: Закрыто, 1: Открыто) |

- **Технологическая норма:** 24.0 .. 28.0 °C.
- **Стресс-сценарий:** При открытии жарочной печи (`HR:0003 = 1`) происходит выброс тепла (+5.0 °C в объем цеха). Автоматика форсирует вытяжной зонт ВЗ-101 и подает сигнал упреждающего охлаждения в Зону 2.

---

### Зона 2: Холодный цех глазировки тортов (Критический контур HACCP)

| Адрес (Dec) | Идентификатор | Тип данных | Диапазон | Ед. изм. | Описание |
|---|---|---|---|---|---|
| **0010** | `Z2_TEMP_ACTUAL` | INT16 (RO) | 0 .. 500 | 0.1 °C | Температура продукта и воздуха в зоне глазировки |
| **0011** | `Z2_HUM_ACTUAL` | INT16 (RO) | 0 .. 1000 | 0.1 % Rh | Относительная влажность чистой зоны |
| **0012** | `Z2_CHILLER_PWR` | INT16 (RW) | 0 .. 100 | 1 % | Мощность инверторного прецизионного чиллера AC-201 |
| **0013** | `Z2_HUMIDIFIER` | INT16 (RW) | 0 .. 100 | 1 % | Мощность парового увлажнителя HUM-201 |

- **Регламент HACCP:** Строго 18.5 .. 19.5 °C (при температуре > 20.0 °C возникает риск таяния и дефекта поседения шоколада).
- **Базовая уставка:** Дневная смена: 19.0 °C; Ночной дежурный режим: 23.5 °C.
- **Алгоритм управления:** ПИД-регулирование частоты вращения компрессора чиллера с компенсацией теплопритока через смежную стену из Зоны 1.

---

### Зона 3: Склад муки и зона разгрузки (Сухое сыпучее сырье)

| Адрес (Dec) | Идентификатор | Тип данных | Диапазон | Ед. изм. | Описание |
|---|---|---|---|---|---|
| **0020** | `Z3_TEMP_ACTUAL` | INT16 (RO) | 0 .. 500 | 0.1 °C | Температура воздуха на складе сырья |
| **0021** | `Z3_HUM_ACTUAL` | INT16 (RO) | 0 .. 1000 | 0.1 % Rh | Относительная влажность воздуха в зоне стеллажей |
| **0022** | `Z3_DEHUM_PWR` | INT16 (RW) | 0 .. 100 | 1 % | Мощность адсорбционного роторного осушителя DH-301 |
| **0023** | `Z3_BAY_GATE` | INT16 (RW) | 0 .. 1 | bool | Концевой датчик секционных ворот рампы (0: Закрыто, 1: Открыто) |

- **Технологическая норма:** Относительная влажность строго < 50.0 % Rh (гигроскопичное хранение муки и сахара).
- **Стресс-сценарий:** При открытии ворот рампы (`HR:0023 = 1`) происходит подсос сырого уличного воздуха до 70-75 % Rh. Контроллер предиктивно включает адсорбционный осушитель DH-301 на 80-100%.

---

### Контур цехового освещения (Щит ЩО-1 / BMS Lighting)

| Адрес (Dec) | Идентификатор | Тип данных | Диапазон | Ед. изм. | Описание |
|---|---|---|---|---|---|
| **0030** | `LIGHT_Z1_DIM` | INT16 (RW) | 0 .. 100 | 1 % | Яркость световой линии Зоны 1 (Выпечка) |
| **0031** | `LIGHT_Z2_DIM` | INT16 (RW) | 0 .. 100 | 1 % | Яркость световой линии Зоны 2 (Глазировка) |
| **0032** | `LIGHT_Z3_DIM` | INT16 (RW) | 0 .. 100 | 1 % | Яркость световой линии Зоны 3 (Склад) |

- **Дневная смена:** 100% (540 люкс, санитарная норма СанПиН для пищевых производств).
- **Ночная смена:** 30% (~140 люкс, энергосберегающий дежурный режим).
- **Управление:** Индивидуальное диммирование через контроллер ЩО-1 (протокол DALI / 0-10V).
