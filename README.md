# BMS HVAC Controller

Прототип контроллера для объединения систем вентиляции, кондиционирования и увлажнения в единый пульт управления.

Демо в облаке: https://bms-hvac.onrender.com

---

## В чем суть проекта

На большинстве производств и складов климатическое оборудование работает порознь:
- у кондиционера свой пульт;
- у вытяжки свой тумблер;
- у увлажнителя свой датчик на стене.

Из-за этого они часто мешают друг другу: кондиционер охлаждает и сушит воздух, увлажнитель пытается его нагреть и увлажнить, а вентиляция выдувает весь подготовленный воздух на улицу. Это приводит к лишним счетам за свет и перепадам температуры (например, на кондитерском производстве из-за этого плывет шоколадная глазурь).

Этот проект — прототип контроллера, который собирает показания всех приборов по промышленному протоколу Modbus и управляет ими согласованно: вы задаете одну целевую температуру и влажность, а софт сам распределяет нагрузку между вытяжкой, холодом и увлажнением.

---

## Что реализовано в прототипе

1. **Сервер автоматики (Python / FastAPI):**
   - опрашивает устройства по протоколу Modbus TCP (порт 5020);
   - крутит алгоритм регулирования: если рядом открыли печь или ворота склада, система автоматически прибавляет холод или включает осушитель;
   - считает примерный расход киловатт и экономию.

2. **Веб-панель оператора:**
   - 3D-модель помещения цеха (Three.js) с воздуховодами и агрегатами;
   - кнопки стресс-тестов (открыть печь, открыть ворота, переключить на ночной режим);
   - график температур в реальном времени;
   - внизу страницы — 3D-схема шкафа автоматики на DIN-рейке (как собирать контроллер в железе).

3. **База данных и отчеты:**
   - данные сохраняются в локальную базу SQLite каждые 5 секунд;
   - кнопка «Журнал HACCP (CSV)» скачивает готовую таблицу за последние 24 часа для проверок санэпидемстанции (открывается в обычном Excel).

## Как запустить проект у себя

Требуется Python 3.10 или выше.

```bash
# 1. Склонировать репозиторий
git clone https://github.com/sulejmenRPG/bms-hvac.git
cd bms-hvac

# 2. Создать и активировать окружение
python -m venv .venv
.\.venv\Scripts\activate   # на Windows
source .venv/bin/activate  # на Linux / macOS

# 3. Установить библиотеки
pip install -r requirements.txt

# 4. Запустить
python run_bms.py
```

После запуска в браузере откроется адрес `http://127.0.0.1:8000`.

## Структура файлов

- `run_bms.py` — главный файл запуска (поднимает симулятор цеха и веб-сервер).
- `simulator/climate_room.py` — симулятор Modbus TCP (моделирует 3 зоны: выпечка, цех, склад).
- `web/server.py` — веб-сервер FastAPI и логика опроса.
- `web/telemetry_db.py` — сохранение в базу SQLite и генерация CSV-отчета.
- `web/static/` — фронтенд (HTML, стили, 3D-модели на Three.js).
- `docs/HARDWARE_TEST.md` — как собрать тестовый стенд на столе за 10 000 тенге.
