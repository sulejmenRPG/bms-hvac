# BMS HVAC Edge Controller & Digital Twin Platform

Промышленный шлюз-контроллер и система диспетчеризации микроклимата (BMS / SCADA) для пищевых производств, складов и технологических цехов.

Решение объединяет разрозненные контуры вентиляции (AHU/VAV), охлаждения (чиллеры/кондиционеры) и увлажнения в единую автоматизированную систему управления с поддержкой стандарта Modbus TCP/RTU и визуализацией в виде интерактивного 3D цифрового двойника.

---

## 1. Решаемая проблема

На большинстве фабрик и складов климатическое оборудование работает изолированно:
- Кондиционеры охлаждают и сушат воздух.
- Пароувлажнители борются с кондиционерами и греют воздух.
- Приточная вентиляция выбрасывает подготовленный воздух на улицу.

**Результат раздельного управления:** повышенный износ оборудования, брак чувствительного сырья (таяние шоколадной глазури, комкование муки) и перерасход электроэнергии до 35%.

**Решение платформы:** единая точка уставки температуры и влажности. Алгоритм координирует частотные приводы вытяжки, клапаны охлаждения и ступени увлажнения, предотвращая конфликты систем.

## 2. Основные компоненты системы

### Цифровой двойник цеха (3D WebGL / Three.js)
- Интерактивная аксонометрическая модель технологического цеха (3 зоны: печи, глазировка, склад).
- Трассировка вентиляционных каналов: приточный воздуховод, VAV-терминалы, диффузоры.
- Инспектор оборудования по клику: паспорт агрегата, адреса Modbus-регистров, оперативные параметры.

### 3D-модель физического шкафа автоматики (DIN-Rail TS-35)
- Промышленный компьютер Advantech IPC на DIN-рейке.
- Блок питания MeanWell 24V DC с защитой от перегрузок.
- Съемные клеммные блоки Phoenix Contact PA 6.6 (порт RS-485 COM1) с кабельной маркировкой.
- Модули ввода-вывода (Pt100 RTD, 0-10V, 24V DI/DO).

### Энергонезависимая база данных и журнал HACCP
- Локальная база данных SQLite (`bms_telemetry.db`) на контроллере.
- Непрерывная фиксация температур, влажности, энергопотребления и допусков HACCP каждые 5 секунд.
- Экспорт официального отчета санэпидемстанции в один клик: `haccp_journal_glazing.csv` (UTF-8 BOM, совместимость с русскоязычным Microsoft Excel).

### Энергоаудитор (ВРУ-0.4кВ)
- Расчет мгновенной активной мощности и холодильного коэффициента COP.
- Сравнение с традиционной базовой схемой без автоматики.
- Расчет финансовой экономии в тенге (тариф 38.50 ₸ / кВт·ч).

## 3. Быстрый запуск

### Требования
- Python 3.10 или новее
- ОС: Windows, Linux или macOS

### Установка зависимостей
```bash
git clone https://github.com/sulejmenRPG/bms-hvac.git
cd bms-hvac
python -m venv .venv

# Активация окружения (Windows):
.\.venv\Scripts\activate
# Активация окружения (Linux/macOS):
source .venv/bin/activate

pip install -r requirements.txt
```

### Запуск системы
```bash
python run_bms.py
```

После старта:
- **Modbus TCP сервер:** `127.0.0.1:5020` (ID: 1)
- **Веб-панель диспетчера:** `http://127.0.0.1:8000/` (откроется автоматически в браузере)

## 5. План перехода в физическое оборудование (Стенд)

Для перехода от программного симулятора к первому физическому стенду требуется:
1. **Адаптер шины:** USB-RS485 конвертер на чипе FTDI или CH340 (~2 500 ₸).
2. **Датчик температуры и влажности:** промышленный датчик Modbus RTU RS-485 (XY-MD02 или SHT20, ~4 500 ₸).
3. **Хост-контроллер:** любой мини-ПК на Linux/Windows или Raspberry Pi / Orange Pi.
4. **Интеграция:** в `web/server.py` адрес подключения переключается с виртуального сокета TCP на последовательный порт `AsyncModbusSerialClient(port='COM3', baudrate=9600)`.
